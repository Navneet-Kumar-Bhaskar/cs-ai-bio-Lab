# 🧬 CS × AI × Biology Lab

> **50+ projects at the intersection of Computer Science, Artificial Intelligence, and Biology.**

This repository documents my journey of **learning by building**.

Instead of only learning concepts from courses and books, I am turning what I learn into practical projects across **Computer Science, AI, and Biology**.

Every project is documented here so that the code, experiments, results, and progress are publicly available.

# 🔬 How Each Project Is Documented

Every project aims to contain:

* **Problem** — What problem am I solving?
* **Idea** — How does the solution work?
* **Concepts** — What did I learn?
* **Implementation** — Source code
* **Testing** — How was it tested?
* **Results** — What happened?
* **Demo** — Working demonstration where applicable
* **Limitations** — What doesn't work yet?
* **Future Work** — What could be improved?

The goal is not to pretend that every project is perfect.

The goal is to show the **real progression from beginner implementations to advanced systems**.
